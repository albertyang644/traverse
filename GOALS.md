# GOALS.md

Basically make a simplified version of xplorer2 from windows; but in KDE using QT libs.

Create a simple file manager that allows for bookmarks; quick launch icons on top; filter bar on top; integrated search of current dir and all directories below it with simple matching and wild card matching.  

Tree on the left pane; and single pane; with the option to do double pane; remembers what the dir was in the double pane.  

Every action can have a hotkey attached to it; so a settings menu for it.  A bash action can also be attached to a hotkey.  

Create dir, create new file (with preset extension).  and of course; basic CRUD.

Also; add/remove columns; and sort by columns.  Settings of no confirm or confirm for delete.  Long Click to rename or hot key or menu item.
